# 👕 Workit Analytics: Limpieza, Homologación y Análisis Transaccional B2B

## 📌 Estado del Proyecto
Este repositorio documenta el procesamiento, ingeniería de datos y análisis exploratorio sobre la base de datos de vestuario corporativo B2B (*Workit*).

## 📊 Datos Procesados
* **Total de Registros Transaccionales:** 14,839 pedidos procesados[cite: 1].
* **Cobertura de Clientes:** 10,519 clientes únicos (RUTs)[cite: 1].
* **Homologación de Giros:** Normalización y estructuración de 232 giros comerciales en sectores económicos clave[cite: 1].

## 🛠️ Stack Tecnológico Utilizado
* **Lenguaje:** Python 3
* **Entorno:** Jupyter Notebook
* **Librerías:** Pandas, NumPy, Re (Expresiones Regulares)
